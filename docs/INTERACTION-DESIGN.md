# 交互路径设计（INTERACTION-DESIGN）v1.2 · GTN 小葡宝

状态：✅ v1.2（v0.5.0 用户反馈：缺多系列指标——「检查与指标」二级页签 + 指标管理）。签认时机：G1 同批（与 SCENARIOS、页面树一起）。
硬约束继承：原型是唯一视觉基准；demo 唯一数据源；无判读列；页脚贴底；字号 12.5–15px；面板 25–45% 可拖可收；治疗线 32 号折叠卡；AI 按钮走 `gtn:agent-draft` 一键携带提示词+病情上下文、不自动发送。

**§0 修订（v1.2 · 2026-10-25）**：二级结构二选一中，选择「把 hCG 一级页扩为带二级页签的『检查与指标』页」，不新增全局菜单项——理由：24 号规范明确"不把每种化验拆成全局菜单；化验分类收在页内 Tab"，且家族一级导航 12 页的口径（IP2 的 P1–P10 双向覆盖）不被破坏。多系列红线：数值照抄、单位恒随行；**无参考区间带、无高低判定文案**（"参考区间"只允许作为报告原文照抄的 note 语境出现）；化疗疗程起止日以中性竖条背景标注（档案事实，非判定）；schema 0005 metric_series/metric_points 不设 ref_low/ref_high 判定列。

## 1. 场景路径表（六要素）

| ID/场景 | 入口（看板文案，逐字） | 步骤（AI 默认 / 手工收敛） | 产物 | 回首页 | 失败恢复 |
|---|---|---|---|---|---|
| P1/S1 录 hCG | 「接下来」卡「本周 hCG 复查」 | AI：对话/拍照上传化验单 → 候选（日期/数值/单位）逐项核对 → 确认；手工：「⋯ 更多」→「手工补一条」（数字键盘，≤6 字段） | hCG 记录 +1，曲线更新 | 保存 Toast「回到看板」或顶栏品牌 | 候选拒收零副作用；解析失败标「未核实」留候选区 |
| P2/S2 记疗程 | 看板「最近疗程」卡「+ 记一个疗程」 | 手工默认（疗程信息通常无结构化单据）：新建折叠卡（序号/方案/起止/当日 hCG ≤6 字段）；AI：口述疗程经过 → 候选卡核对 | 疗程折叠卡 +1 | 卡片收起 + Toast「回到看板」 | 更正=新增版本，旧值版本链可查 |
| P3/S3 诊断留底 | 看板「诊断档案」卡「FIGO 评分留个底」 | 手工：8 项原始分照抄报告（每项三态/数字键盘）→ 总分自动求和；AI：拍照病理/出院小结 → 原文摘录候选 | 评分自录表 1 份 + 病理摘录条目 +1 | 「回到看板」 | 分值项未填显式空态；仅求和不解释 |
| P4/S4 随访月记录 | 「接下来」卡「第 N 个月随访 hCG」 | AI：上传当月化验单 → 候选核对；手工：「⋯ 更多」补录 | 随访月记录 +1（日历打点） | Toast「回到看板」 | 未到月月份置灰不可预填 |
| P5/S5 报告导入 | 看板「资料」卡「导入报告」 | 选文件 → 云解析逐文件授权 → 候选区逐项核对 → 入档 | 档案条目 +N | 「回到看板」 | 拒收/失败条目留候选区标「未核实」，零副作用 |
| P6/S6 复诊材料 | 「接下来」卡「复诊前准备」 | 勾选范围（时间线/疗程/评分/问题清单）→ 生成 → 预览 | 材料 1 份（与档案同源） | 「回到看板」 | 生成失败保留草稿勾选 |
| P7/设置 | 各业务页右上齿轮 | 改目录/解析模式/凭据状态展示 → 保存 | 设置生效 | 「回到看板」 | 取消无副作用；换目录不清库 |
| P8/S7 营养记录 | 看板「支持线」卡「记一餐与口腔情况」 | AI 默认：拍餐盘照片 → 候选（日期/餐次/吃了什么）逐项核对；手工：「⋯ 更多」→「手工记一餐」（≤6 字段，口腔情况与叶酸照医嘱原文） | 饮食记录 +1；体重序列可补点 | 「回到看板」 | 候选拒收零副作用；口腔溃疡影响只按自述记录，不给处理方案 |
| P9/S6 情绪记录 | 看板「支持线」卡「写一条情绪记录」 | 手工默认（私密内容不走 AI 候选）：三态单选 + 一句自述 → 保存；等报告日单列（记一个等报告日，3 字段） | 情绪/等报告日记录 +1（私密仅本机） | 「回到看板」 | 私密记录不进复诊材料与 AI 上下文；心理资源清单空态如实「未核实」 |

| P11/指标管理 | 检查与指标页二级页签「指标管理」 | 手工默认收敛：序列清单（名/单位/记录数/最近值+日期/迷你 spark/来源）→ ① 序列显隐设置（隐藏只不画线，记录不删）② AI 导入候选（gtn:agent-draft 只起草不代发，核对前不入事实层）③「⋯ 更多」手工补录一个值（数字键盘 ≤4 字段）；分节走 section_titles 心智（血 hCG / 血常规 / 肝肾功能 / 体重） | 序列记录 +1（对应二级页签曲线更新）或显隐设置生效 | Toast 提示或顶栏品牌回看板 | 候选拒收零副作用；更正已入档值走「改这一条」=新增版本，旧值进版本链，无裸删除 |

## 2. CRUD 双通道矩阵

| 实体 | AI 协助（默认） | 手工（收敛） | 说明与红线 |
|---|---|---|---|
| hCG 记录 | 拍化验单 → 候选（日期/数值/单位/医院） | 「⋯ 更多」数字键盘 ≤5 字段 | 数值原文照抄；无高低/正常判定输出 |
| 化疗疗程卡 | 口述经过 → 候选卡 | 「+ 记一个疗程」≤6 字段折叠卡 | 无疗效判定字段；更正=新增版本 |
| 事件标记（平台/反弹/达正常锚点） | — 红线：不做 AI 事件判定 | 记录条目「标记此点」三态单选 | 事件由患者依医嘱口径勾选，系统不提示结论 |
| FIGO 评分自录表 | 拍照报告 → 仅定位候选（不 AI 估分） | 8 项照抄，数字键盘 | 红线：不 AI 估算评分、不输出低危/高危 |
| 末次妊娠档案 | 拍病历 → 候选核对 | 「⋯ 更多」≤6 字段 | 病理仅原文摘录 |
| 随访月记录 | 上传化验单 → 候选 | 「⋯ 更多」补录 | 不输出"安全/可怀孕" |
| 问题清单/复诊材料 | AI 草稿按钮 `gtn:agent-draft` 预写提示词进输入框（不自动发送） | 勾选生成 | 材料与档案同源（唯一数据源） |
| 资料档案条目 | MinerU 导入候选 | — | 候选未核对不入事实层 |

## 3. 门槛红线 IP1–IP10 验法（本项目）

- IP1 本文档 v1.0 随 G1 签认后 HTML 才开工（PROTOTYPE-REVIEW 引用版本）。
- IP2 无头脚本穷举 `(view,sub)` × 路径表：12 一级页均被 P1–P11 覆盖，孤儿页=0；「检查与指标」的二级页签是 view 内 sub，不另占一级页。
- IP3 入口文案逐字 diff：文档 §1 入口列 = dashboard 渲染文案 = 导航 key。
- IP4 每条路径走完断言"记录 +1 / 材料 1 份"且回看板可点。
- IP5 候选必核对：拒收后候选区与事实层无变化（脚本断言）。
- IP6 每页显式编辑入口 ≤1；手工入口收在「⋯ 更多」；表单 ≤6 字段。
- IP7 全部数字输入（hCG 值/评分/日期）用键盘组件。
- IP8 `grep "不可恢复"` = 0；更正后旧版本在版本链可见。
- IP9 双通道同源：hCG 手工与 AI 各写一次，事实层同一条版本链。
- IP10 AI 示例点击后输入框有预写提示词且无发送动作（34 号契约 + 原生输入自动发送守卫）。
