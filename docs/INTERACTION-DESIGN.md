# 交互路径设计（INTERACTION-DESIGN）v0.1 骨架

状态：🔧 M0 骨架 → M2 前按 starter 28 号（IP1）出全量：每个一期场景一条"首页入口→步骤→产物→回首页"路径 + CRUD 双通道矩阵（AI 协助默认、手工可及收敛、删除=更正）。

## 硬约束（继承家族纪律）

- 原型是唯一视觉基准，开发版逐字符对齐；demo 唯一数据源。
- 前端页脚贴底；字号 12.5–15px；面板宽 25–45% 可拖可收；无判读列；`[hidden]` 控制显隐。
- 治疗线用 32 号折叠卡模版（32-TREATMENT-PATHWAY-FOLDOUT），打印展开需 beforeprint JS。
- AI 按钮走 `xxx:agent-draft` 一键携带提示词+病情上下文（34 号契约）；原生输入自动发送守卫。
- 窄宽第一版按 30 号（RESPONSIVE-RULES）。
- SVG 图表根 `class="chart"`，smoothPath 用 Fritsch–Carlson；分类数据不进趋势图。
