## 一级功能重名率实测（vs breast-cancer-workbench v0.12.0）

基准一级功能（public/js/pages-basic.js:10-19）：看板/病情整理/病情一图秀/临床/营养支持/心理支持/全程与康复/收藏与回顾（8 项）。

GTN 规划 7 项一级功能逐项判定：
- ① hCG 序列时间线 → **不重名**（hCG 为 GTN 特异指标序列语义）
- ② 化疗疗程折叠卡档案 → **不重名**（按疗程折叠卡组织为 GTN 特有形态）
- ③ FIGO 评分自录表+末次妊娠档案 → **不重名**（GTN 独有数据域）
- ④ 治愈后随访日历（避孕/再生育）→ **不重名**（治愈后节点+再生育记录 GTN 特有）
- ⑤ 报告导入（MinerU）→ 重名（家族通用链路）
- ⑥ 复诊准备 → 重名（通用功能）
- ⑦ 全局设置页 → 重名（脚手架通用页面）

**重名 3/7 = 42.9% ≤ 70% ✅**（宽松口径上限 5/7=71%，取严格"名称或语义实质相同"口径）。
