# 患者主流程（PATIENT-FLOW）v0.1 骨架

状态：🔧 M0 骨架，M1 按场景签认后升 v1.0。每条功能线挂一句患者原话（当前为改写占位句，0 访谈如实声明，M1 有访谈后替换为一手引语）。

服务主体：患者本人为主（育龄女性），照护者（伴侣/家属）兼容代记。**红线：医生任务冒充患者需要＝独立评审一票否决项。**

## 病程阶段主线（葡萄胎清宫起 → 再生育）

1. **清宫后随访期**：每周 hCG 报告回家 → 录入数值/日期/单位 → 曲线上看走势（只画线不判读） → 平台期/反弹事件由患者依医嘱口径勾选留痕。患者原话占位："我想自己看到那条线往下走，心里才踏实。"
2. **GTN 诊断期**：整理末次妊娠档案 + 清宫病理原文 + FIGO 评分自录表 → 就诊时一页纸调出。占位："医生说的那些分期数字，我想留个底。"
3. **化疗期**：每疗程结束当天记疗程折叠卡（方案/起止/当日 hCG/感受） → 疗程串成治疗线 → 副作用日记可选记录。占位："第几疗、哪天上的药，别等我忘了。"
4. **hCG 治愈线**：以患者录入的"hCG 达正常（医嘱口径）"日期为锚，画在时间线上 → 自动转入随访日历。占位："降到正常那天我想标记出来。"
5. **治愈后随访与再生育**：按月记录 hCG + 避孕方式 + 再生育计划 → 复诊准备材料。占位："说好查一年，哪个月该查我自己记不清。"

## 双通道 CRUD

每条记录线 AI 协助（报告导入解析候选）默认 + 手工可及；删除＝更更正留痕，不清事实。详见 INTERACTION-DESIGN（M1 按 28 号出全量）。

## 失败与退出

导入失败/解析不确定 → 候选区如实标"未核实"；任何阶段可退回手工；不做任何诊断/治疗建议输出。
