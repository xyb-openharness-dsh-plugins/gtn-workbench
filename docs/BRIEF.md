# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：妊娠滋养细胞肿瘤（GTN）患者本人为主（育龄女性），照护者（伴侣/家属）兼容代记；葡萄胎清宫后随访阶段与GTN化疗及治愈后随访阶段均覆盖

场景：葡萄胎清宫后每周hCG血清报告追踪与平台期/反弹事件留痕；GTN诊断线索整理（末次妊娠档案、清宫病理、FIGO解剖学分期与预后评分表自录）；化疗疗程档案（疗程序号/方案/起止日/当日hCG，折叠卡）；治愈后12个月随访日历与避孕方式、再生育计划记录；就诊准备材料生成

核心流程：
1. 选择本机资料目录并导入hCG化验单/清宫病理/影像报告
2. 核对候选信息，建立末次妊娠档案与hCG序列时间线
3. 记录化疗疗程（折叠卡）与每次复查hCG
4. 治愈后按随访日历逐月记录hCG与避孕/再生育计划
5. 生成复诊准备与医患沟通材料

完成结果：得到来源可追溯、可核对的个人病程档案：hCG序列时间线（对数轴）、化疗疗程折叠卡档案、末次妊娠与评分整理表、随访日历与再生育记录、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
